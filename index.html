Windows Clipboard Viewer

Inspect all clipboard contents that the browser can access — including text, HTML, images, and files. The browser Clipboard API exposes data in your clipboard and its various types. This page leverages this API to allow you to see text, images, html, and files as well as further alter, copy, or use the different types for your purposes. Tables are extracted from html and downloadable to CSV and TSV for convenience.

Press Ctrl+V anywhere on the page to inspect your clipboard.

Things to try: paste code from VS Code to see HTML color formatting. Paste vector images from draw.io to see the raw vector parameters.
